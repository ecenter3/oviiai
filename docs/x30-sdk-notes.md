# X30 SDK 筆記（robotserver_sdk v0.1.0）

來源：https://github.com/DeepRoboticsLab/robotserver_sdk （MIT）

## 協定
- TCP 連 106 導航主機，預設 `192.168.1.106:30000`。原廠禁止把 SDK 裝在 106 或其他機上主機，要從外部電腦連。
- 標頭 16 byte：`EB 90 EB 90` + 本文長度 uint16 LE + 序號 uint16 LE + 8 byte 0。本文為 XML（根節點 `PatrolDevice`）。
- 回應以序號對應請求。1002/1004/1007 一問一答（SDK 逾時 3 秒）；1003 在整條路線結束後才回一次。

| Type | 用途 | 平台指令 |
|---|---|---|
| 1002 | 即時狀態：位置、姿態、速度、電量、定位、充電、電機 | telemetry |
| 1003 | 導航任務：一串導航點 | navigate / patrol |
| 1004 | 取消任務 | stop / pause |
| 1007 | 查詢任務狀態 | （轉接器內部用） |

## 對平台的影響
- 導航點座標是 X30 自己地圖的座標，地圖與路線要先用手把建立（X30 Pro 應用手冊）。平台用座標校正轉換。
- **上位機連線中斷 → 任務自動停止（41802）**。轉接器主機必須 24 小時在線。
- 錯誤碼有「自主充電」系列（41794–41797、41806），表示機器支援自主充電，但 SDK 沒有觸發指令。

## 充電狀態對應
平台以遙測 `state = "charging"` 或 `battery.charging = true` 判斷在樁上（見 `adapters/anbot/README.md`「充電」一節，所有轉接器相同）。
X30 的 1002 狀態有「充電」欄位，轉接器要把它對應到 `battery.charging`；上樁後即使運動狀態仍是待機也要回報 true。
