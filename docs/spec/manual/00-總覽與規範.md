## 2. 技術選型

以下為定案，全部開源、無授權費。版本取開發當下的穩定版並在 lock 檔固定。

| 層 | 選用 | 理由 |
| --- | --- | --- |
| 語言 | TypeScript（後端、前端、共用型別）；Python 3.11（轉接器） | 前後端共用型別；宇樹與雲深處 SDK 有 Python 版 |
| 後端框架 | NestJS 10、Node.js 22 LTS | 模組化、依賴注入、易於分工 |
| 資料庫 | PostgreSQL 16 ＋ TimescaleDB 2 | 一般資料與遙測時序共用一個庫 |
| 資料存取 | Kysely（型別安全查詢）＋ node-pg-migrate（SQL 遷移檔） | 「資料庫」分頁的 SQL 即為遷移內容 |
| 快取與佇列 | Redis 7（機器人即時狀態、分散鎖、BullMQ 排程佇列） | 排程與重試 |
| 訊息匯流排 | EMQX 5（MQTT 5） | 轉接器與後端解耦；內建管理介面 |
| 檔案儲存 | MinIO（S3 相容） | 抓拍、錄影、平面圖 |
| 影像 | MediaMTX（RTSP → WebRTC） | 單一執行檔、不轉碼 |
| 前端 | React 18 ＋ Vite ＋ TypeScript、React Router、TanStack Query、Zustand | 主流、好招人 |
| 前端圖表與地圖 | ECharts；平面圖用 SVG 元件自繪 | 平面圖只是底圖＋座標點，不需地圖引擎 |
| 驗證 | JWT（存取 15 分鐘＋更新 7 天 httpOnly cookie）、argon2 密碼雜湊 | 獨立登入 |
| 資料驗證 | zod（前後端共用 schema）；Python 端 pydantic | 同一份格式定義 |
| 測試 | Vitest（單元）、Supertest（API）、Playwright（端對端）、pytest（轉接器） |  |
| 部署 | Docker Compose、Nginx（反向代理＋TLS）、GitHub Actions（CI） | 場內單機部署 |

全系統的單位：距離公尺、角度弧度、電量百分比、時間以 UTC 存、以 Asia/Taipei 顯示。介面文字一律經 i18n 檔（zh-TW），不寫死在元件裡。

## 4. 開發規範

**分支與提交**

- `main` 受保護，只能透過合併請求（PR）合併，需 CI 通過與 1 人審查。
- 分支名：`feat/T-23-dispatch-select`、`fix/T-41-battery-null`，編號對應工作清單。
- 提交訊息採 Conventional Commits：`feat(dispatch): 依距離選車`。
- 每個 PR 只做一件事，說明改了什麼、怎麼測、截圖（介面類）。

**命名與資料**

- 資料庫表與欄位 snake\_case；API JSON 欄位 camelCase；TypeScript 型別 PascalCase。
- 主鍵一律 UUID；機器人另有人看的代碼 `ANBOT-001`、`B2-001`、`X30-001`。
- 狀態、等級、權限碼等常數只定義在 `packages/shared`，前後端共用。
- 所有可調的閾值（電量、信心度、逾時）放在 `settings` 表，不寫死。

**設定與秘密**

- 所有連線資訊與密碼從環境變數讀（`.env`），`.env.example` 列出全部鍵名；秘密不進 Git。
- 攝影機 RTSP 帳密、機器人連線密鑰存資料庫時加密（pgcrypto，金鑰取自環境變數）。

**日誌**

- 後端以 JSON 格式輸出（pino），每筆帶 `robotId`、`taskId`、`cmdId`（如有）。
- 使用者操作另寫 `op_logs`，和系統日誌分開。

**完成定義（每個工作項目）**

- [ ] 功能符合規格書與工作清單的驗收條件
- [ ] 核心邏輯有單元測試，CI 通過
- [ ] 在模擬器環境可展示（需實機的項目另需現場確認）
- [ ] 權限與操作日誌已接上
- [ ] 相關文件（API、設定、操作說明）已更新

## 5. 開發順序與里程碑

原則：先做模擬器與統一格式，讓平台在沒有實機時就能完整跑起來；實機到了只是「換一個轉接器」。

| 里程碑 | 週次 | 內容 | 可展示的成果 |
| --- | --- | --- | --- |
| M0 骨架 | W1–2 | 程式庫、CI、Docker 開發環境、資料庫遷移、登入權限、共用格式、模擬器 | 28 台模擬機器人登入後在監控頁移動 |
| M1 核心 | W3–5 | 機器人狀態、派工、充電、告警、導航管理、管理設置 | 模擬器下完整派工／回充／告警流程 |
| M2 接實機 | W5–7 | 萬為、宇樹轉接器、遙控、影像、對講、人臉串接、座標校正 | 各 1 台實機可導航、回充、看影像 |
| M3 現場整合 | W8–10 | 18 台上線、建圖、攝影機全接、壓力測試 | 連續 8 小時自動巡邏 |
| M4 試運行 | W11–12 | 修正、教育訓練、驗收 | 2027/1/1 上線 |
| P2 | 2027 Q1 | 雲深處、報表類、環境、媒體、版本、簡訊、上位系統 | 依第二期驗收 |

細項與相依關係見「工作清單」分頁。
