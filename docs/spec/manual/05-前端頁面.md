# 前端頁面

畫面、排版、配色與互動一律以原型 `docs/prototype/oviiai-monitor.html` 為準；原型用瀏覽器打開即可操作，其中的假資料與模擬邏輯改為呼叫 API。

## 1. 前端架構

| 項目 | 做法 |
| --- | --- |
| 版面 | 左側分組選單＋上方列（樓層、告警鈴、使用者）＋內容區；廣頁面內容區為「主區＋右側 290 px 篩選欄」 |
| 路由 | React Router，每頁一個路由，路由設定帶權限碼；無權限不顯示選單、直接輸入網址導向 403 頁 |
| 伺服器資料 | TanStack Query；列表類頁面用伺服器端分頁 |
| 即時資料 | 單一 Socket.IO 連線，事件寫入 Zustand store（robots、alarms、chargers）；任務與告警事件同時 invalidate 對應查詢 |
| 驗證 | accessToken 放記憶體；401 自動呼叫 /auth/refresh 重試一次，失敗回登入頁 |
| 主題 | 深色主題，色彩與字型照原型 CSS 變數（Noto Sans TC、JetBrains Mono） |
| 文字 | 全部走 i18n（zh-TW），狀態與等級名稱從 shared 常數對照 |
| 響應式 | 控制室以 1920×1080 為主；手機寬度可瀏覽不破版即可 |

## 2. 共用元件

| 元件 | 用途 |
| --- | --- |
| `FloorMap` | SVG 平面圖：底圖、縮放平移、機器人（位置＋朝向＋狀態色）、攝影機、充電樁、路徑、區域、告警點；支援點選取座標（導航管理、校正用） |
| `RobotCard`、`RobotBadge` | 機器人狀態卡、狀態標籤、電量條 |
| `VideoPlayer` | WebRTC 播放（WHEP），含載入、重連、斷線狀態 |
| `Joystick` | 遙控搖桿＋鍵盤 WASD，每 100 ms 送 teleop |
| `DataTable` | 分頁、排序、勾選、匯出 CSV |
| `DateRangeCalendar` | 日期區間（原型右側日曆） |
| `FilterPanel` | 右側篩選欄 |
| `AlarmPopup` | P1 全螢幕彈窗＋響鈴（Web Audio，需使用者先點過頁面才能發聲） |
| `LevelTag`、`StatusTag` | 告警等級與處理狀態標籤 |
| `ConfirmDialog`、`FormDialog` | 確認與表單彈窗 |
| `PermGate` | 依權限顯示或隱藏子元件 |
| `LineChart`、`PieChart` | ECharts 包裝 |

**場域快速設定（第一期追加，原型無對應畫面）**

| 頁面 | 路由 | 權限 | 重點互動 |
| --- | --- | --- | --- |
| 場域匯出／匯入 | /site | settings | 匯出按鈕；匯入後先顯示差異表（新增／修改／刪除），確認才套用 |
| 批次匯入 | 地圖管理、機器人管理頁內 | maps、robotmgr | 下載範本、上傳、逐列結果表、只匯入正確列 |
| 新場域設定精靈 | /setup | settings | 左側步驟清單與完成勾選；每步嵌入對應管理頁的表單；系統空白時登入後自動開啟 |

**前端驗收共同條件**：空資料、載入中、錯誤三種狀態都有畫面；所有破壞性操作（急停解除、刪除、駁回）先確認；即時資料斷線時上方顯示「連線中斷」。
